# 🧘‍♂️ MediMantra - Meditation Timer Android App

**MediMantra** is a calming, intuitive meditation timer Android app that helps users customize their meditation sessions with music, warm-up, and silence periods. Built with Java and XML in Android Studio, the app offers a peaceful experience for both beginner and experienced meditators.

---

## 📱 Features

- 🎵 **Select Background Music** from a scrollable list
- ⏱️ **Custom Timer Inputs**: Set warm-up, meditation, and end-silence durations
- 🔘 **Start Timer Button** to begin session with all selected options
- 🖼️ Beautiful **gradient background and smooth UI**
- 🔙 Easy **navigation with back button**

---

## 🧩 Tech Stack

- **Language**: Java
- **UI Design**: XML Layouts
- **Platform**: Android (min SDK 21 - Lollipop)
- **IDE**: Android Studio
